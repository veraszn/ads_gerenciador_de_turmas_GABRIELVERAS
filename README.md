# ads_gerenciador_de_turmas_GABRIELVERAS

Este é um projeto voltado a isntituições de ensino contendo diversas funções que não podem faltar em um sistema de gerenciar alunos, pode ser muito útil em qualquer institução deste meio. 

Para executar este código basta inseri-lo no Visual Studio Code e em seguida instalar a extensão "Live Server" e clicar com o botão direito do mouse no arquivo html e depois executar, apenas isso e depois aproveitar todas as funcionalidades do programa.
